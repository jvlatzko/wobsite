# wobsite

Personal portfolio website for Vincent Latzko, Operations Specialist based in Dresden, Germany.

**Visit:** https://jvlatzko.github.io/wobsite/

## About

This is a static website built with [Hugo](https://gohugo.io/), featuring information about experience, skills, and services in operations, cloud architecture, and IT consulting.

## Building

The site is automatically built and deployed via GitHub Actions on every push to `main`.

To build locally:
```bash
hugo
```

The generated site will be in the `public/` directory.
